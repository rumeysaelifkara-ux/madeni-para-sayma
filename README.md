
# Madeni Para Sayma Projesi

## Projenin amacı
OpenCV kullanarak bir görüntüdeki madeni paraları daire tespiti yöntemiyle saymak.

## Kullanılan teknolojiler
- Python
- OpenCV
- Hough Circle Transform

## Çalıştırma
Gerekli kütüphaneleri yükleyin:

    pip install -r requirements.txt

Ardından ana programı çalıştırın:

    python src/main.py

Test fotoğrafını images/para.jpg konumuna yerleştirin.
